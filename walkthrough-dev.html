📋 Rise Jobs · Walkthrough

How the job board works — from browsing to applying
1

📌 Job board loads (index.html)

The app fetches live jobs from the Rise API using the /jobs/public and /jobs/openjobs endpoints. It displays job cards with company name, title, location, and type.

GET https://api.joinrise.io/api/v1/jobs/public?page=1&limit=10&sort=desc&sortedBy=createdAt
FEATURES Search · Filters (Hybrid, Remote, Startup, Legal, Growth, Operations) · Pagination
2

🔎 User interaction — search & filters

Users can search by job title, company name, or location. Filters change the API endpoint to fetch category-specific jobs (e.g., ?jobType=Hybrid or ?department=Legal,Compliance).

// Filter mapping → API parameters Hybrid → jobType=Hybrid Remote → featuredCategory=Remote Startup → companySize=startup Legal → department=Legal,Compliance Growth → department=Growth,Strategy,Consulting,... Operations→ department=Growth,Strategy,Consulting,Operations,...
3

🖱️ Click "Apply →" on a job card

Each job card has an "Apply →" link that points to single-job.html with the job ID as a query parameter.

<a href="single-job.html?id=6a300247e1138d5e3e591843" class="job-link"> Apply → </a>

⚡ The job ID is passed via URL so the detail page knows which job to fetch.

4

📄 Job detail page loads (single-job.html)

The detail page extracts the job ID from the URL, fetches the full job data (including description), and displays a rich view with:

  • Company logo & name
  • Full job title & location
  • Complete job description (HTML formatted)
  • "Apply now" button that leads to the actual application URL
// single-job.html reads the ID const jobId = new URLSearchParams(window.location.search).get('id'); // Then fetches job details from API fetch(`https://api.joinrise.io/api/v1/jobs/public?includeDescription=true`) .then(res => res.json()) .then(data => { const job = data.result.jobs.find(j => j._id === jobId); // render full details });
5

🚀 Click "Apply now" → external application

The "Apply now" button on the detail page links directly to the company's application URL (e.g., Lever, Greenhouse, SmartRecruiters, etc.). This opens in a new tab so the user can apply on the official site.

<a href="https://jobs.lever.co/trustedhousesitters.com/..." target="_blank" rel="noopener noreferrer" class="apply-btn"> Apply now → </a>

✅ The user sees the full job description before being redirected, ensuring they have all the context.

📌 Key takeaways

  • Two-page flow: Job board → Detail page → External application
  • Job ID is passed via URL query parameter (?id=...)
  • Search & filters are applied client-side or via API parameters
  • Pagination is handled with page and limit parameters
  • Responsive design works on all screen sizes
